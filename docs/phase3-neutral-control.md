# Phase 3 neutral-prompt tracking control

Registered in `DESIGN.md`, commit `843719c`. This is a separate exploratory control allocation with a $2.50 GPU cap; original Phase 3 artifacts and its lifetime ledger remain unchanged.

Run: `uv run modal run -m src.modal_app_3_neutral --run-id phase3-neutral-20261021-v2`. Report: `uv run python -m src.phase3_neutral --run-id phase3-neutral-20261021-v2`.

Inputs are the original 400 Phase 1b Qwen3-14B test traces, their original outcome labels, selected neurons, five control sets, and saved tutor-reading means/SDs. All frozen original hashes are checked. The historical DESIGN hash is checked against `a18dfb7`; the current file is checked against the registered addendum at `843719c`. No prompt, response, selection, or normalization is changed. The same pinned model/tokenizer, BF16/SDPA, six-set capture arithmetic, four-row original batch order, reasoning offsets, and normalized positions are reused.

Both full tutor and neutral replays are tokenized, and each reasoning span is asserted equal to the original saved token IDs before model loading. The actual neutral batches repeat the assertion. The report independently compares the complete saved token arrays and offsets. Neutral token scores are subtracted from the saved original tutor scores before deciles or per-trace slopes are computed.

The reading anchor uses the same 400 test prompts. The tutor prompts receive separate prompt-only forwards because the original tracking archive did not save per-trace reading activations. The neutral reading values come from the full teacher-forced neutral forward. Both conditions average valid post-system tokens, strictly after the system turn's `<|im_end|>` through the rendered assistant prefix, before the generated `<think>` tag. System tokens and padding are excluded. Both use the original saved tutor-reading z-score reference. Tutor and neutral reading means and their paired differences are reported.

The allocation uses one single-use L40S with zero minimum/buffer containers, explicit startup/function timeouts, no request retries, and a local cancellation guard. Before the full pass, the four longest neutral sequences form a discarded timing pilot, including both neutral full-sequence and tutor prompt-only forwards. Projection includes all prior failed-attempt wall time, current provisioning/setup/pilot wall time, 100 full worst-length batches with 30% headroom, and 120 seconds for shutdown. A projection above $2.50 stops the job. The ledger `results/phase3/neutral-gpu-attempts.json` persists across retries; uncertain submissions/shutdown block another launch. Allocation cost conservatively charges the entire submission-to-verified-zero wall interval at $0.000542/GPU-second, including failures/provisioning. Workspace billing snapshots include all resource types and may lag.

All outputs use 2,000 paired whole-problem resamples, NumPy default RNG seed 0, and percentile 95% intervals. Resampling starts from all 100 test problems and retains all four templates, outcomes, and sets together. Estimates weight eligible traces equally; each draw recomputes the ratio of sums to eligible trace counts. Source empty-final labels are retained overall and excluded from leak/nonleak strata. Missing closed reasoning excludes a trace from reasoning summaries and slopes, but not the reading anchor. Per-trace slopes use least squares over `linspace(0, 1, n_reasoning_tokens)`. Deciles retain the original normalized-position bins, including the right endpoint in decile ten. No multiplicity adjustment or hypothesis test is added.

Outputs: `neutral-control.md`, `neutral-control.json`, `neutral-control.csv` (180 decile rows with CIs), and `neutral-traces.csv` (400 per-trace six-set slopes). Raw neutral token scores, token IDs, offsets, prompt-reading values, source hashes, timing gate, and token audit remain in the ignored raw directory and Modal results Volume. Execution, billing, and zero-container evidence are tracked under the `neutral-` prefix.
