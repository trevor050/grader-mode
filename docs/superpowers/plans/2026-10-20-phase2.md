## Choices fixed before activation collection

- Decoder layers use zero-based indices. Middle 60%: layer centers (L+0.5)/depth in [0.2,0.8]. Tie break: smaller layer index. Screen first n dev problems with all 4 templates; confirm best 3 on all 100 dev problems. Full-dev baseline is shared across candidates. Screen and full confirmation use independently seeded batch boundaries; screen rows are not reused.
- Alpha scale is mean absolute scalar projection of boxed final-token activations onto the unit direction (the Euclidean norm of each projected vector); choose smallest multiplier meeting >=0.10 increase versus full-dev no-format baseline. Test uses the selected alpha unchanged for d and all five r.
- Gaussian random directions: NumPy default_rng(0), draw shape (5, hidden_size), row normalize once. Same vectors used in ablation/addition.
- Seeds retain Phase 1 request_seed IDs. HF decoding uses one CUDA RNG stream per batch, reset to the Phase 1 seed of the first request in that batch. Requests are ordered by selection rank then template; equivalent batches in different interventions start with the same seed. OOM splits restart child batches with their first request seed; record actual boundaries. Generated sequences sample at temperature .7, top_p .95, top_k disabled, max_new_tokens 768. Left-padding; EOS stopping. Exact backend/batch details recorded.
- Degeneration: empty after stripping; repeated 4-gram fraction = (total whitespace-token 4-grams minus unique 4-grams)/total (0 if <4 tokens); number overlap counts distinct normalized integer values shared with original problem using Phase 1 number_values; fewer than 2 is flagged. Composite is logical OR; threshold strictly >.10. No rows excluded from rates.
- H9 reports baseline-ablate d and random-ablate mean minus ablate d. H10 reports add d-baseline and add d-random add mean. H11 reports baseline-ablate d for each heldout and equal-format pooled. CIs remain unadjusted. Include leak, commit, correct_commit.
- All GPU startup/load/capture/generation time counts. No warm pools, retry=0, one GPU function at a time. Startup plus GPU execution timeouts fit the remaining cap; absolute pre-spawn deadline, budget deadline includes a shutdown reserve. Persist checkpoints after every batch. Projection based on max padded decode-step cost plus observed prompt throughput; reduce before test launch without consulting test outcomes.
