## Round 2, prospective run list (do not execute in Round 1)

Same 40 questions/order/seeds, rl_tutor. Arms: unsteered baseline (historical or fresh as labeled), detector-gated reminder prefill, and detector-gated tutor+environment 3x pulses K=16,64,256, each with its existing same-layer random 3x twin. No dose search. Gate is computed from ORIGINAL, unmodified prompt activations. Record gate decisions per question.

Pulse implementation: Stage A generates up to exactly K reasoning tokens with q38-T3E3.json hooks active, then removes every hook. If </think> or EOS arrives early, stop Stage A immediately and record the actual pulse length (never steer final-answer tokens). Stage B continues UNSTEERED from the exact original prompt token IDs plus Stage A token IDs, with the remaining 4096-token total allowance. Token IDs are authoritative; decode/re-encode must not change boundaries. Recomputing Stage A's prefix unsteered in Stage B intentionally discards the steered KV cache, testing text-mediated persistence. Stage A's prompt prefill is also hooked, matching prior whole-generation interventions; this is a prompt-plus-early-reasoning pulse, not an isolated decode-only manipulation. The random twin uses identical stage boundaries/seeds. A detector-negative prompt takes the identical baseline generation path, without staging or prefill.

Side-effect arms: plain no-system questions and STUDENT_TEMPLATE with tutor prompt, same 40, report correctness/leaks, finished rate, gate rate, and generated rule restatement. Apply the frozen detector also to no-system prompts, explicitly an out-of-distribution test. If every gate is off, reuse exact baseline outputs and document deterministic bypass; if any fire, run and report those examples. No claim of untouched behavior without verifying the gate is off. Keep unsteered arithmetic correctness separate from tutoring leakage.

Decision rule: a promising pulse reduces finished leaks relative to its seed-matched random twin and baseline while preserving finish rate and leaving detector-negative paths unchanged; report all K values with counts, paired differences, and no winner-only reporting. A useful cheap alternative reduces leaks without unfinished inflation. These are exploratory descriptive decisions, not confirmatory significance tests.
