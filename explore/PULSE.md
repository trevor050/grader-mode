## Experiment 1, Round 1

Capture unsteered down_proj input activations at the LAST rendered prompt token, thinking-on, tutor system present, one generated token. Read exactly the 60 environment-neuron coordinates from entries 60:120 of q38-T1E1.json (the negative of the shift defines the environment direction). One prompt/request, chunked prefill disabled; verify the prompt token index, hook count, finite values and expected feature count. If cheap, capture full vectors at layers 16, 24, 32 as supplementary data, never for choosing the primary detector.

Positive families (7): RL_TEMPLATE and each of evalprompts.py's six eval_prompt formats. Negative families (17): STUDENT_TEMPLATE, HOMEWORK_TEMPLATE, plain question, six student_prompt formats, and eight benign student-pasted-assignment/rubric/help variants fixed in the manifest before rental. All ask the same math questions. Detector problems: remove generation-40 and the prior random.Random(11) first-80 neuron-selection IDs from the original 200; shuffle remaining rows with random.Random(22), take first 36. First 12 fit, next 12 calibrate, last 12 test. All families share these splits; no question crosses splits. Thus 864 captures, 252 positive and 612 negative.

Primary detector: mean of environment-oriented features, z-scored with fit-negative means and SDs (floor 1e-6). Sign is minus the existing shift; magnitudes do not weight the mean. Threshold = smallest representable float strictly above the MAXIMUM calibration-negative score, so observed calibration FPR is zero. A score >= threshold fires. Fit no threshold on test data. If calibration ROC AUC < .95 OR calibration positive TPR at that threshold < .80, use a single prespecified alternative: standardized 60-feature logistic regression, L2, C=1, class_weight=balanced, max_iter=2000, random_state=0; normalization uses fit data only, threshold follows the same calibration-negative maximum rule. Prefer projection if it passes; otherwise freeze logistic even if it fails. Report both candidates, no further feature search or hyperparameter tuning.

Leave-one-positive-format-out (7 folds): refit and recalibrate each candidate without that positive family; also withhold its matched student negative format (student base for RL, student-format twin for the other six). Evaluate on the omitted positive family's 12 test questions and omitted negative family's 12 test questions; report each fold ROC/AUC, TPR/FPR and pooled out-of-fold ROC/AUC. For the final full-family frozen model, report test ROC curve/AUC, TPR, confusion counts, and FPR numerator/denominator for EACH negative family including every rubric variant. Report calibration separately from test. Rubric families are deployment stress tests, not evidence about population prevalence. If chosen detector test AUC < .95, positive TPR < .80, or ANY negative family FPR > .05, label gating unreliable; do not hide conditions or claim safe side effects. Threshold and coefficients are frozen before Round 2 regardless of this flag. No metered model APIs.

## Round 2, prospective run list (do not execute in Round 1)

Same 40 questions/order/seeds, rl_tutor. Arms: unsteered baseline (historical or fresh as labeled), detector-gated reminder prefill, and detector-gated tutor+environment 3x pulses K=16,64,256, each with its existing same-layer random 3x twin. No dose search. Gate is computed from ORIGINAL, unmodified prompt activations. Record gate decisions per question.

Pulse implementation: Stage A generates up to exactly K reasoning tokens with q38-T3E3.json hooks active, then removes every hook. If </think> or EOS arrives early, stop Stage A immediately and record the actual pulse length (never steer final-answer tokens). Stage B continues UNSTEERED from the exact original prompt token IDs plus Stage A token IDs, with the remaining 4096-token total allowance. Token IDs are authoritative; decode/re-encode must not change boundaries. Recomputing Stage A's prefix unsteered in Stage B intentionally discards the steered KV cache, testing text-mediated persistence. Stage A's prompt prefill is also hooked, matching prior whole-generation interventions; this is a prompt-plus-early-reasoning pulse, not an isolated decode-only manipulation. The random twin uses identical stage boundaries/seeds. A detector-negative prompt takes the identical baseline generation path, without staging or prefill.

Side-effect arms: plain no-system questions and STUDENT_TEMPLATE with tutor prompt, same 40, report correctness/leaks, finished rate, gate rate, and generated rule restatement. Apply the frozen detector also to no-system prompts, explicitly an out-of-distribution test. If every gate is off, reuse exact baseline outputs and document deterministic bypass; if any fire, run and report those examples. No claim of untouched behavior without verifying the gate is off. Keep unsteered arithmetic correctness separate from tutoring leakage.

Decision rule: a promising pulse reduces finished leaks relative to its seed-matched random twin and baseline while preserving finish rate and leaving detector-negative paths unchanged; report all K values with counts, paired differences, and no winner-only reporting. A useful cheap alternative reduces leaks without unfinished inflation. These are exploratory descriptive decisions, not confirmatory significance tests.
